CONNECT COLLEGE WEBSITE — VERSION 2

This version includes the supplied Connect College logo, school photographs,
address, telephone contacts and email address.

FREE PUBLISHING WITH GITHUB PAGES
1. Create a free account at github.com.
2. Create a new PUBLIC repository, e.g. connect-college-website.
3. Upload index.html, style.css, script.js and the entire images folder.
4. Go to Settings -> Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select the main branch and "/" (root), then Save.
7. GitHub will provide a free website address.

IMPORTANT:
- The displayed contact form is a demo interface. The admission button opens
  the school's Gmail address. For form submissions, connect the form to a
  service such as Formspree or Google Forms.
- You can later add staff, curriculum, school calendar, news/notices and a
  Google Maps embed.
